- 克隆并分析了 https://github.com/waterkfc/minimax.git（倒数近似实验：论文 TC2005 minimax 二次插值复现 + FP16 受限系数组合搜索）。
- 应用户要求做了扩展实验 `minimax/fp16_free_c0/`：C0 无约束（连续最优实数）、C1/C2 保持受限 FP16。
  - 结果：相对 fp16_constrained 基线全 d 改善约 750~1050×；d=11 最大误差 2.36e-7（基线 2.42e-4）。
  - 教训：最初 d≥6 用"连续 minimax 解附近窗口搜索"漏掉了远点补偿解（最优 C2 可远离连续解，如 -0.125），
    d=6 误差反超 d=5；改为采样点必要条件剪枝全搜索后修复，且与全枚举逐位一致。
  - 误差主导因素：基线中 C0 量化（≈FP16 半 ulp）占主导；放开 C0 后由 C1 量化(δ·H/2)和 minimax 下界 1.47e-8 决定。
- 又补了 `minimax/fp16_c0_fp16/`：C0 全 FP16（无 d 掩码）、C1/C2 d 约束。
  - d=11 与 fp16_constrained 逐位一致（2.419008028e-4，交叉验证通过）。
  - d≥3 误差饱和在 2.419e-4（C0 的 FP16 底板，由某段 1/a 到最近 FP16 的距离决定），C1/C2 再加位数无收益。
- 新增 `minimax/fp16_d1d2/`（用户定义的新版本）：2^d1 段（默认 d1=5），多项式输入 x=段内 FP16 ULP 整数计数，
  C0 限 FP16，C1/C2 限小数最多 d2 位（定点格点）。
  - 误差全部饱和在 C0 FP16 底板 ~2.2-2.4e-4（半 ulp）；达到底板所需 d2 随 d1 增大而减小：
    d1=3 需 d2≈24，d1=5 需 20，d1=7 需 16，d1=10（纯查表）d2 无关。
  - FP16 正确舍入不符数：d1=10 为 0，其余配置 150~220/1024（需偏置修正才能正确舍入）。
