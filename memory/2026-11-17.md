# 2026-11-17

- 用户反馈 fp16_d1d2 中 C1/C2 大量为 0（裸 2^-d2 格点与实际量级不匹配），要求按导数范围加缩放因子。
- 范围核对：用户给的 C1「负 2^6 到 2^9」、C2「2^-18 到 2^21」有误。正确推导（Δ=t·2^-10）：
  - C1 = f'·2^-10，f'=-1/x²∈[-2^0,-2^-2] → C1 ∈ [-2^-10, -2^-12]（恒负）。
    用户偏差疑似把 x² 范围当 [1,8]（那是 x³）。
  - C2 = (f''/2)·2^-20，f''/2=1/x³∈[2^-3,2^0] → C2 ∈ [2^-23, 2^-20]（恒正）。
    用户的范围大 4 倍（2 位），疑似 f″ 与 f″/2、2^-19 与 2^-20 混用。
  - 实验拟合值佐证：seg0 C1≈-2^-10.03、C2≈2^-20.03 ✓。
- 新增 `minimax/fp16_d1d2_scaled/`：C1/C2 实际范围（±1/16 余量）映射 2^d2 档，
  C=lo+m·step（m 无符号 d2 位，符号由偏移承担），C1 恒负 C2 恒正，不再为 0。
  - 结果：d1=5 配 d2=5~6 即达 C0 FP16 底板 2.30e-4（≈0.47 输出 ulp）；
    同 d2=8 旧方案 1.47e-2 vs 新 2.30e-4（64×）；d1=3 需 d2=6，d1=7 需 d2=4。
  - 结论：ROM 每段只需 C0(16b) + C1(6b) + C2(6b) 即可达 0.5 ulp 级倒数。
- 新增 `minimax/fp16_d1d2_pow2/`（用户嫌仿射缩放复杂，改纯 2^n 移位缩放）：
  范围最大值对齐 2^d2，无符号 m∈[0,2^d2-1]；C1=-m1·2^-(d2+10)，C2=m2·2^-(d2+20)。
  - 饱和点与仿射版几乎一致（d1=5 需 d2=6、d1=7 需 5、d1=3 需 8），
    仅极低 d2(2~4) 比仿射版差 1.3~2×。甜点不变：d1=5,d2=6 → 28 bit/段。
- 已推送到 gush596/minimax（fp16_d1d2_scaled + 记忆）。
